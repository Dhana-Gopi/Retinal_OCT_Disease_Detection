Sample images for testing the Streamlit app (src/inference.py / app.py)
=======================================================================

1) Real OCT scans (12 files)
   <CLASS>_test_<original file name>.jpeg
   - 3 scans per class (CNV, DME, DRUSEN, NORMAL), chosen at random (seeded)
     from the TEST split of the Hugging Face dataset
     zacharielegault/Kermany2017-OCT (Kermany et al., 2018).
   - The files are the ORIGINAL, unprocessed JPEG bytes exactly as stored in
     the dataset (8-bit grayscale, 1024x496 or 1536x496 pixels). No resizing,
     padding or normalisation has been applied - the app must do that itself
     with src.preprocessing.preprocess_pil().
   - The class prefix is the ground-truth label. The original file name is
     <CLASS>-<patient id>-<scan number>.jpeg.
   - These come from the held-out test split, which is never used for
     training or model selection.

2) invalid_not_an_image.jpg
   A plain text file with a .jpg extension. The app should reject it with a
   friendly "invalid or corrupted image" message (load_image_bytes raises
   ValueError).

3) non_oct_colour_example.png
   A synthetic 400x300 RGB colour gradient - a valid image file that is NOT
   a retinal OCT scan. It decodes fine, so it tests the app's handling of
   out-of-distribution input (e.g. a colour warning / low-confidence notice).
   The classifier will still output one of the 4 classes for it; that
   prediction is meaningless.

Generated by the data agent (see src/data_checks.py for dataset checks).
